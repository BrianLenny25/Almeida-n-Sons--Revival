# Almeida ’N Sons Revival LLC | Launch-ready website files

This static site includes a real, homeowner-approved Charleston project gallery, mobile navigation, business contacts, services, policies, and an estimate inquiry form.

## Preview
Open `index.html` in a browser. For a local preview that correctly serves images, run `python -m http.server 8000` in this folder and visit `http://localhost:8000`.

## Important: estimate requests
The estimate form currently uses `mailto:` to compose an email to AlmeidaNSonsrevivalLLC@gmail.com. The customer must have an email app configured and must press **Send**. This is **not** a server-backed submission system and cannot upload photos automatically. Customers can attach photos to the drafted email manually or email/call the business directly. Do not advertise the form as a guaranteed server-delivered submission. To support in-browser submissions and image uploads, connect a third-party form provider with the business owner's account and verify its limits before switching.

## Publish for free on GitHub Pages
1. Sign into GitHub and create a new **public** repository, e.g. `almeida-revival-site`.
2. Upload the **contents** of this folder (`index.html`, `styles.css`, `script.js`, and the `assets` directory) to the repository root.
3. Open **Settings → Pages → Build and deployment → Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. Wait for the site to deploy, open the published `https://USERNAME.github.io/almeida-revival-site/` link, and test the navigation, image loading, phone link, and estimate-email flow on your phone.
5. Share the resulting URL on Facebook, Instagram, Snapchat, and TikTok.

No website has been deployed by ChatGPT; publishing requires your GitHub account. GitHub Pages is publicly accessible. The current hero/service background images are illustrative remote Unsplash imagery, while the **Our Work** gallery uses actual provided project photographs. The logo is a typographic placeholder until your approved logo file is supplied. Do not misrepresent illustrative photos as customer projects.

The site uses Google Fonts and Unsplash images, which require internet access.
